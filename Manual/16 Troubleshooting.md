## The dashboards show code instead of tables

The plugins are switched off. Open Settings (⚙️ bottom-left) → **Community plugins** → **Turn on community plugins**. Then close and reopen Obsidian.

## A table or board is empty or looks broken

Make sure Obsidian is up to date: Settings → **General** → **Check for updates**. The tables and boards need version 1.13 or newer.

## I can't type in a note

You're in Reading view. Press `Ctrl+E` (Windows) or `Cmd+E` (Mac). See [03 Obsidian basics](03%20Obsidian%20basics.md).

## My note isn't showing on the module dashboard

Check three things in the note's properties:

1. `course` links to the module, e.g. `[[MG472]]`.
2. `type` is spelled exactly right, e.g. `Lecture` with a capital L.
3. The note is inside that module's folder (for lectures and seminars).

See [08 Taking notes](08%20Taking%20notes.md).

## A to-do isn't showing on the Main Dashboard

It needs to be under a `### TODO` heading, or have a due date in the next 7 days. See [11 To-dos](11%20To-dos.md).

## A deadline isn't showing

Check its `type` is `Assessment` or `Deadline`, and that the note is in the module's `Deadlines` folder. See [10 Deadlines](10%20Deadlines.md).

## Word or PowerPoint files won't preview

Install LibreOffice, then quit Obsidian completely and reopen it. See [02 Install and set up](02%20Install%20and%20set%20up.md).

## I broke a dashboard

Download the template again from GitHub, and copy just that one file back into your vault. Your notes are separate files, so they're safe.

## I deleted something by accident

Look in your computer's bin (Recycle Bin on Windows). Obsidian can also restore earlier versions of a note: open the note, press `Ctrl+P` / `Cmd+P`, and type "file recovery".
