Everything here happens in the **left sidebar** (the file explorer).

## Make a new note

> **Best way:** use the **+ New** button on a dashboard. It puts the note in the right folder and fills in the module for you. See [08 Taking notes](08%20Taking%20notes.md).

Other ways, for notes that aren't for a module:

- Press `Ctrl+N` / `Cmd+N`.
- Or right-click a folder in the sidebar and choose **New note**. The note is made inside that folder.

## Rename a note

- Click the note's name at the very top of the note and type the new name.
- Or right-click it in the sidebar and choose **Rename**.

Renaming is safe: Obsidian updates every link to that note automatically.

Avoid these characters in names, because they can't be used in file names: `/ \ : * ? " < > |`

## Move a note

Drag it to another folder in the sidebar. Links keep working.

> [!WARNING]
> Notes for a module must stay inside that module's folder, otherwise they disappear from its dashboard. See [08 Taking notes](08%20Taking%20notes.md).

## Copy a note

Right-click it and choose **Make a copy**.

## Delete a note

Right-click it and choose **Delete**, then confirm. Deleted notes go to your computer's bin (Recycle Bin on Windows), so you can get them back.

## Make a new folder

Right-click the folder you want it inside and choose **New folder**.

## Add lecture slides, PDFs and other files

1. Find the file in Finder (Mac) or File Explorer (Windows), e.g. in your Downloads.
2. Drag it onto the right folder in Obsidian's sidebar.

| File | Where it goes |
| --- | --- |
| Lecture slides and handouts | That module's `00 Meta` folder |
| Reading and case PDFs | `01 UNI/03 Literature/PDFs` |
| Books (PDF) | `Books` |

You can also copy files into those folders using Finder or File Explorer, and Obsidian notices them straight away.

PDFs open inside Obsidian, where you can highlight them. Word and PowerPoint files open too, once LibreOffice is installed (see [02 Install and set up](02%20Install%20and%20set%20up.md)).

## Add a screenshot or image

1. Copy the image (or take a screenshot).
2. In Editing view, click where you want it in your note.
3. Paste with `Ctrl+V` / `Cmd+V`.

The image is saved into `00 Meta/Attachments` automatically. You never need to open that folder.

## Find a note's file on your computer

Right-click the note and choose **Reveal in Finder** (Mac) or **Show in system explorer** (Windows).
