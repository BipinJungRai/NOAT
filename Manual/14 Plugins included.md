Plugins are add-ons that give Obsidian extra features. All of these are already installed and set up, so you don't need to do anything.

| Plugin | What it does for you |
| --- | --- |
| **Dataview** | Powers the live counts and to-do lists on the dashboards |
| **Tasks** | Lets to-dos have due dates (📅). See [11 To-dos](11%20To-dos.md) |
| **Homepage** | Opens the Main Dashboard every time you start Obsidian |
| **PDF++** | Better PDF reading: highlight text and link to the exact spot |
| **Doc Preview** | Shows Word and PowerPoint files inside Obsidian (needs LibreOffice, see [02 Install and set up](02%20Install%20and%20set%20up.md)) |
| **Dynamic Outline** | A clickable list of headings, for jumping around long notes |
| **Editing Toolbar** | A formatting toolbar (bold, headings, lists) so you don't need shortcuts |
| **Omnisearch** | A smarter search. Press `Ctrl+P` / `Cmd+P` and type "Omnisearch" |
| **Excalidraw** | Hand-drawn diagrams. `Ctrl+P` / `Cmd+P` → "Excalidraw: Create new drawing" |
| **Calendar** | A calendar in the right sidebar. Click a day to make a daily note |
| **Kanban** | Extra drag-and-drop to-do boards, if you want one |
| **Templater** | Note templates, for later if you want them |
| **Pixel Banner** | The banner picture at the top of the Main Dashboard. Add a `banner` property to any of your own notes to give it one too |
| **Iconize** | Icons on folders in the sidebar |
| **File Explorer++** | Keeps the most-used notes pinned at the top of the sidebar |
| **File Explorer Note Count** | Shows how many notes each folder has |
| **Clear Unused Images** | Deletes screenshots that no note uses any more. `Ctrl+P` / `Cmd+P` → "Clear Unused Images" |
| **Style Settings** | Extra options for some themes |

## Turning plugins on or off

Settings (⚙️ bottom-left) → **Community plugins**. Each plugin has a switch. Please leave Dataview, Tasks and Homepage on, because the dashboards need them.

## Updating plugins

Settings → **Community plugins** → **Check for updates**. This is optional: the template already comes with working versions.

## Thanks

These plugins are made by volunteers in the Obsidian community. The full list of authors is in the [README](../README.md).
